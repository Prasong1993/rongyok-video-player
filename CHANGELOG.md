# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-28

### Added
- ✅ Initial release of Rongyok Video Player Pro
- ✅ Auto-play next episode functionality
- ✅ Resume playback from last position
- ✅ Auto-save progress every 5 seconds
- ✅ Seek slider with timeline
- ✅ Volume control
- ✅ Playback speed adjustment (0.25x - 2x)
- ✅ Fullscreen mode
- ✅ Episode list sidebar
- ✅ Watch history tracking
- ✅ Local storage persistence
- ✅ Dark theme UI
- ✅ Mobile responsive design
- ✅ Keyboard shortcuts support
- ✅ Debug logging
- ✅ Standalone HTML player
- ✅ Userscript version
- ✅ Comprehensive documentation

### Features
- Plyr player integration
- Discord CDN support
- Series-specific watch history
- Configurable auto-save interval
- Beautiful UI with gradient theme
- Cross-browser compatibility

### Browser Support
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+
- Opera 67+

### Known Limitations
- Requires Tampermonkey for userscript
- Some features limited on mobile
- CORS restrictions on some CDNs
- Video duration may not load immediately
